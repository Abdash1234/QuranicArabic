# Arabic Revision Trainer

Open `index.html` in a browser (or host the folder on GitHub Pages). No build step.

- Add vocab in `data/vocab.js` (lists 1–40): `{ ar: "كِتَابٌ", en: "a book" }`
- Add exercises in `data/exercises.js` (1–40): `{ q: "question", a: "answer" }`
- Optional `note: "..."` on any card.

Modes: Flashcards (flip), Match (vocab), Quiz (vocab). Mix multiple lists, shuffle, reverse direction, and track "known" cards (saved in your browser).
